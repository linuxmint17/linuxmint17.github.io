关键字与标识符

经常考察的关键字

  • const * 常量 和指针一起 考察
  • voliate * 容易修改，禁止编译器优化，嵌入式，和多线程环境
  • extern * 外部引用，声明
  • static * 本文件，或者本函数可用，本类可用
  • auto * 自动变量、栈变量， 类型推导
  • register * 请求编译器将 变量放到寄存器

不常见的关键字

  • restrict *
